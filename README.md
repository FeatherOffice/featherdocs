# FeatherDocs

**Editor de documentos da suíte FeatherOffice, em Rust com interface nativa Iced.**

> **Em desenvolvimento.** O código ainda não foi publicado neste repositório.
> A versão alpha está prevista para **30/10/2026**.

## O que vem aí

- Editor contínuo, com estilos, numeração e desfazer/refazer.
- `.docx` lido e gravado em Rust, sem conversores externos.
- LaTeX com painel de código ao lado do papel e fórmulas matemáticas.
- Markdown para editar e ver lado a lado.
- Bibliografia, campos e revisão de texto.
- Formato próprio `.fdoz`, com o histórico de versões guardado dentro do arquivo.

## Privacidade

Tudo roda na sua máquina: sem conta, sem login, sem telemetria.
